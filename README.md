# Apartment

A minimal Greenways Gaussian-splat world backed by one SOG asset.

Open it in Greenways OS with:

```text
https://github.com/greenways-worlds/apartment
```

The root [`project.edn`](project.edn) supplies the initial camera, background,
and repository-relative asset path.
